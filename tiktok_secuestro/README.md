# TikTok: «Si te secuestran…»

Vídeo vertical 1080x1920 (~57 s) con personajes animados en estilo plano, iluminación de bombilla,
subtítulos grandes palabra a palabra, voz neuronal, música de tensión y efectos (latidos, puerta, sirena).

Consejos basados en recomendaciones generales de supervivencia en secuestros (mantener la calma,
observar, humanizarse, no provocar, conservar fuerzas y, sobre todo, el comportamiento durante el rescate).

```bash
python3 voz.py && python3 video.py          # -> secuestro_tiktok.mp4
python3 video.py --preview 3 20 44          # fotogramas sueltos en build/
```
