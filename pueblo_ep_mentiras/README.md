# «En este pueblo, si mientes… te crece la cabeza» (ficción original)

Vídeo vertical 1080x1920 (~84 s) que aplica el análisis del vídeo de referencia de 2,5 M de visualizaciones:
regla del pueblo enseñada en los primeros 3 s, pueblo de día en tonos pastel, narrador en primera persona (Nico),
diálogos con voz propia (Tito, el alcalde Don Ramiro, los vecinos), cortes cada ~1,4 s con ángulos variados,
subtítulos en la zona media-baja con la palabra clave en color, icono recurrente «¡MENTIRA!» y final con giro
de humor («yo dije que este vídeo duraba un minuto»).

Elenco fijo: Nico (gorra naranja, sudadera azul cielo), Don Ramiro (chistera enorme, traje morado, bigote
blanco), Tito (camiseta amarilla, pantalón rojo), Carmen (vestido rosa, rizos naranja) y Pepe (jersey a rayas).

```bash
python3 voz.py && python3 video.py          # -> pueblo_mentiras.mp4
```
