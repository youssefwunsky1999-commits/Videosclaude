# TikTok: «Si tu coche cae al agua…»

Vídeo vertical 1080x1920 (~57 s): el coche cae de un puente y se hunde en corte transversal, con
cuenta atrás de 60 s, agua subiendo dentro de la cabina, cristal que se rompe, burbujas, voz neuronal,
subtítulos palabra a palabra, música de urgencia y efectos (salpicadura, tic-tac, cristal).

Contenido basado en el protocolo «Cinturón, Ventana, Niños, Fuera» (Seatbelts–Windows–Children–Out)
del investigador Gordon Giesbrecht (Universidad de Manitoba).

```bash
python3 voz.py && python3 video.py          # -> coche_agua_tiktok.mp4
python3 video.py --preview 6 23 44          # fotogramas sueltos en build/
```
