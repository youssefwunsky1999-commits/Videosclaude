# «En este planeta no hay nadie. Solo yo.» (ficción) — vídeo de arranque de la cuenta

Vídeo vertical 1080x1920 (~64 s) pensado para una cuenta nueva con 0 seguidores: Nico vive solo en un planeta
diminuto (casa, banco y un estadio vacío), grita «¡Hola!» y solo responde el eco. Descubre que cada persona que
sigue la cuenta aparece en el planeta (rayo de luz y «puf»), que el nombre que comentes lo llevará tu personaje
y que compartir trae a un amigo. Metas: 100 seguidores = estadio lleno; 1.000 = una ciudad entera.
Cierre: «Hoy somos 0. ¿Quieres ser el primero?».

```bash
python3 voz.py && python3 video.py          # -> planeta_vacio.mp4
```
